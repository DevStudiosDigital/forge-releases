Install Forge

One file. One command. No internet needed.

Server

  • Linux (amd64 or arm64) with systemd
  • 4 GB disk, 1.5 GB memory, plus the model
  • Ports 8080, 8081, 8084 free
  • Your model: Ollama, vLLM, or another model server, already set up and running. Forge connects to your model; it doesn't include one.
  • Nothing else to install first: the file brings Docker if the server has no Docker or Podman

1Copy the file to the server

forge-install-0.1.8.sh1070 MB

2Run it

server
sudo sh forge-install-0.1.8.sh

It installs Docker if the server has no container engine, then asks for an admin password and your model.

3Done

Control Stationhttp://<server>:8084your admin
Chat APIhttps://<server>:8080/v1key: printed by the installer
MCPhttp://<server>:8081/mcptoken: printed by the installer

Next: sign in, then MCP Server → APIs → Add API.

Ports 8084 and 8081 are plain HTTP. Keep them internal.

Advanced

Own certificate, private CA, Bitwarden, ports
server
sudo sh forge-install-0.1.8.sh --advanced
Install without questions
server
sh forge-install-0.1.8.sh --print-answers > answers
sudo sh forge-install-0.1.8.sh --answers answers

Fill in answers between the two commands.
